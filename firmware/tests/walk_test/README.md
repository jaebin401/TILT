# TILT walk test

`walk_test`는 James Bruton의 YouCanBuildBiPed / Robot003 보행 구조를 TILT의
검증된 서보·기구학·IMU 컴포넌트 위에 최소 구성으로 옮긴 독립 ESP-IDF
프로젝트다. 기존 `pose_test`나 다른 테스트 프로젝트와 연결되지 않는다.

핵심 차이는 다리를 최대 신전에 가깝게 펴지 않는다는 점이다. 기본 긴 다리
96.5 mm와 짧은 다리 90.0 mm는 TILT의 유효 최대 도달 거리 109.5 mm 대비
각각 약 88%, 82%다. 보행은 10 ms 주기로 발 위치 `(x, z)`를 선형 보간한 뒤
매 루프 IK를 풀어 여섯 축을 동기 전송한다.

## 배선과 물리적 안전

- ESP32-S3 `GPIO17 TX → Adapter TXD`, `GPIO18 RX → Adapter RXD`로 직결한다.
- Waveshare Bus Servo Adapter (A)의 UART 점퍼를 A에 둔다.
- 서보 ID는 `11, 12, 13, 21, 22, 23`, 통신 속도는 1 Mbps다.
- 서보는 별도 전원을 사용하고 ESP32와 GND를 공유한다.
- 처음에는 로봇을 바닥에 세우되 양손으로 바로 받칠 준비를 한다.
- 서보 전원을 즉시 끊을 수단을 항상 손 닿는 곳에 둔다. 콘솔의 `!`는 UART
  통신이나 전원 자체가 끊어진 상황을 대신할 수 없다.
- 부팅 시에는 항상 `DISARMED`, 토크 OFF이며 자동으로 움직이지 않는다.

## 빌드와 실행

```bash
source /Users/jae/esp/esp-idf/export.sh
cd firmware/tests/walk_test
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodemXXXX flash monitor
```

권장 순서는 다음과 같다.

1. `status`로 여섯 서보의 응답과 현재 논리 각도를 확인한다.
2. 로봇을 손으로 안전하게 받친 채 `arm`을 입력한다. 현재 여섯 위치를 먼저
   hold goal로 기록한 뒤에만 토크가 켜진다.
3. 필요하면 `joint <name> <-5..+5>`로 각 관절 방향을 작은 각도로 확인한다.
4. `stand`로 기본 긴 다리 높이를 확인한다.
5. `walk`를 입력하면 먼저 같은 stand 자세로 2초 동안 이동하고, 정지 상태의
   walk 모드에 들어간다. 자세를 받친 뒤 space로 보행을 시작한다.

## 보행 구조

`stepTime`(기본 250 ms)은 왼쪽과 오른쪽 다리의 트리거를 번갈아 만들고,
각 다리의 독립 `legTime`(기본 140 ms)은 아래 네 상태를 진행한다. 두 시간을
서로 배수로 맞추지 않는 것이 의도된 위상 구성이다.

1. 트리거를 기다리다가 `z = short`로 다리만 짧게 한다.
2. `x = -legx`로 발만 이동한다.
3. `z = long`으로 다리만 길게 한다.
4. `x = +legx`로 발만 반대편으로 이동하고 대기 상태로 돌아간다.

각 상태는 `x` 또는 `z` 하나만 바꾼다. IK에 전달할 때는 두 다리에 항상
`legx × 0.25`의 전방 바이어스를 더한다. `legx`는 양수와 음수를 모두 허용하므로
실기에서 어느 부호가 전진인지 확인할 수 있다.

## 명령

줄 단위 명령:

| 명령 | 동작 |
| --- | --- |
| `help` | 명령 목록 출력 |
| `status` | 여섯 축 ping, raw tick, 논리 각도 출력 |
| `arm` / `disarm` | 현재 자세를 캡처한 뒤 토크 ON / 토크 OFF |
| `recover` | E-STOP에서 DISARMED로 복구; 이후 다시 `arm` 필요 |
| `!` | 어느 모드에서든 즉시 E-STOP 및 토크 OFF 요청 |
| `home` | ADR-008 zero pose로 2초 보간 이동 |
| `stand` | 양발을 현재 `long_leg` 높이에 둠 |
| `joint <name> <-5..+5>` | 단일 관절 상대 조그 |
| `walk` | stand 자세로 이동한 뒤 문자 입력 walk 모드 진입 |

walk 모드 키:

| 키 | 동작 |
| --- | --- |
| space | 보행 시작/정지. 정지하면 `legx=0`, 양다리는 long으로 복귀 |
| → / `D`, ← / `A` | `legx`를 ±1 mm 조정(범위 -15~+15 mm) |
| ↑ / `W`, ↓ / `S` | long과 short를 함께 ±0.5 mm 조정 |
| `+` / `-` | `long-short` 차이를 ±0.5 mm 조정 |
| `[` / `]` | `stepTime`을 ∓/±10 ms 조정 |
| `{` / `}` | `legTime`을 ∓/±10 ms 조정 |
| `i` | IMU pitch 기반 타이밍 변조 ON/OFF(기본 OFF) |
| `0` | `legx=0` |
| `r` | 표시용 roll/pitch 기준 재설정 |
| `v` | 파라미터, 신전률, IMU, 거부 횟수 출력 |
| `q` | 결과 요약을 출력하고 home으로 복귀 |
| `!` | 즉시 E-STOP |

## IMU와 안전 가드

IMU는 roll/pitch 표시와 선택적 리듬 변조에만 사용한다. `i`를 켜면 절대 pitch
크기에 따라 step time은 240~260 ms, leg time은 130~150 ms 범위에서만
미세 조정된다. IMU 값으로 스윙 다리를 고르거나 자세를 보상하거나 보행을 자동
정지하지 않는다. IMU를 읽을 수 없으면 변조만 꺼지고 보행은 설정된 기본 시간으로
계속된다.

도달 불가 또는 관절 한계 밖의 IK 목표는 클램프해서 보내지 않고 마지막 전송
목표를 유지한다. 거부가 반복되어도 자동 정지하지 않으며 횟수만 집계한다.
300 deg/s 속도 가드는 최후 방어선이다. 발동하면 한 번 경고하고 보행을 정지한 뒤
마지막으로 실제 전송된 목표를 유지한다.

한 보행 사이클(좌우가 각각 한 번 상태 4까지 완료)마다만 한 줄을 출력한다. 종료
요약의 roll/pitch 범위는 관측 정보이며 이동 거리 추정에는 쓰지 않는다. 실제
전진량은 바닥에 표시를 두고 직접 재고, 완료 사이클 수로 나누어 비교한다.
